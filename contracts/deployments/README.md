# Deployment records

One markdown file per real deployment, named by chain and contract version, recording chain and chain id, contract address, deploy transaction, ABI, source commit, tooling versions and date. An entry exists only after a confirmed deployment; no placeholders.

- Testnet address: NOT DEPLOYED
- Mainnet address: NOT DEPLOYED

Verify BOT Chain network/official router/token details at deployment time, not from a stale example. Never commit private keys, mnemonics, production RPC credentials or broadcast files with secrets.
